# goit-js-hw-06

Small demo project for GoIT JavaScript homework exercises (module 6).

## Description

This repository contains simple JavaScript exercise files and a minimal HTML entry point used for learning and testing DOM/JS behaviors.

## Files

- [index.html](index.html)
- [js/task-1.js](js/task-1.js)
- [js/task-2.js](js/task-2.js)
- [js/task-3.js](js/task-3.js)
- [prettierc.json](prettierc.json)

## Setup

No build step required. You can run the examples in a browser or with Node.js (v14+).

## Run

- Open [index.html](index.html) in your browser to load the exercises.
- Or run individual scripts with Node.js from the project root:

```
node js/task-1.js
node js/task-2.js
node js/task-3.js
```

## Formatting

This project includes a Prettier config (prettierc.json). To format the code run:

```
npx prettier --write .
```
